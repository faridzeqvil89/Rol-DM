# Farid Clienta

Captación de Leads para servicios de marketing profesionales.

## Sobre mí

Soy un profesional con experiencia en SEO/AEO/GEO B2B y SaaS.

Sé de SEO técnico, CRO, on page, off page, technical SEO y AI visibility principalmente. Sé crear sitios en WordPress y optimizar Core Web Vitals.

## Objetivo

El punto de este repositorio es crear un flujo de trabajo 100% automatizado con Claude para la captación de clientes para mis servicios: desde identificar y prospectar hasta agendar citas y notificarme.

## Por definir

Debemos definir cosas como:

- Servicios
- Costos
- ICP (perfil de cliente ideal)
- Entre otras
